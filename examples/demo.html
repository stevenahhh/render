HTML & CSS, rendered in Rust

A small engine that parses, styles, lays out and paints a page on the CPU. 한글 텍스트도 시스템 글꼴로 그립니다.

How it works →

Features

Cascade done

Specificity, source order, !important, inheritance and custom properties.

Flexbox row + column

Grow, shrink, wrap, gaps, auto margins and cross-axis alignment.

Text no shaping

Line breaking, font fallback and a cached glyph atlas with subpixel positions.

Text and inline content

Inline elements nest freely: bold, italic, both, underlined, struck, highlighted, monospace and links. Long paragraphs wrap at word boundaries, and whitespace collapses the way it does in a browser.
