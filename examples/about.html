How it works

This page uses no user-agent defaults beyond the built-in sheet and the shared style.css. Press Backspace to go back, or follow this link.

  1. Parse. One pass over the bytes builds an arena DOM with interned names.
  2. Style. Rules are bucketed by id, class and tag, so each element tests few selectors.
  3. Layout. Block, inline and flex layout append a flat display list.
  4. Paint. Visible items are rasterized into the window buffer.

Images, scripts and network loading are out of scope.
